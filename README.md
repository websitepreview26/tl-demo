# Transport Logistics — Telegram Mini App Demo

Демо на основе последней локальной версии Mini App «Вышка 24». Адаптировано под услуги и фирменный стиль https://transport-logistics.by/ (проверено 11 ноября 2026).

## Просмотр
https://websitepreview26.github.io/tl-demo/

## Запуск
Без сборки и зависимостей:

```sh
python3 -m http.server 8875 --directory dist
```

Откройте http://localhost:8875. В `dist/index.html` — оболочка приложения, в `dist/assets/app.js` — логика, в `dist/assets/styles.css` — стили. Все изображения доступны локально.

## Возможности
- Гидроборт: маршрут, груз, вес и объём, дата, время, часы работы и пробег за МКАД.
- Предварительный расчёт: 70 BYN/час, минимум 3 часа, плюс 1,8 BYN/км за МКАД. Пробег вводится пользователем; состав оплачиваемого пробега и окончательная сумма согласуются с менеджером. Тариф не применяется к международным перевозкам.
- Перевозки Беларусь — Россия: маршрут, груз и индивидуальная оценка менеджером.
- Контакт клиента в заявке, комментарии и до 3 фотографий с локальным сжатием.
- Черновик, список заявок, переписка, предложение цены, принятие условий и статусы перевозки.
- Навигация назад, жест с края, нижние вкладки, адаптация к клавиатуре и safe area Telegram.

## Как показать клиенту
1. Выберите услугу или нажмите «Заполнить заявку за меня».
2. Заполните маршрут и груз, затем телефон. Нажмите «Получить стоимость».
3. Внизу экрана раскройте «Демо» → «Открыть режим менеджера».
4. Нажмите «Подставить пример цены и условий» или укажите свою цену и условия. Нажмите «Предложить цену».
5. Через «Демо» вернитесь к клиенту и примите условия.
6. В режиме менеджера согласуйте перевозку и завершите заказ.

Для полного сброса тестовых данных: «Демо» → «Сбросить демо».

## Ограничения демо
Данные хранятся только в localStorage этого браузера. Реальных отправок, платежей, бронирований, уведомлений и синхронизации между устройствами нет. Режим менеджера открыт для демонстрации и не является защищённой административной панелью. Пример 1500 BYN для международной перевозки условный, не тариф компании.

Для запуска в Telegram укажите HTTPS-адрес демо в настройках своего бота через BotFather. Поддерживается Telegram WebApp SDK, включая native BackButton и safe area. Для реальных заявок потребуется серверная часть, проверка initData и защищённый кабинет менеджера. Токены и секреты в проект не включены.

## Публикация
GitHub Pages публикует содержимое `dist/` при отправке изменений в `main` через `.github/workflows/pages.yml`.

Логотип, фотографии и контакты взяты с сайта Transport Logistics и используются для этой демонстрации. Публикация не изменяет основной сайт компании.

Кнопки примера заполняют только пустые поля. На шаге контакта подставляются только имя и тестовый телефон; введённые данные не заменяются.
